The 6-Step Migration Workflow

Step-by-step walkthrough of each stage in the migration console.

1
Connect & Discover
Source and Destination Environment Configuration
SOAP / REST API NTLM / Windows Auth OAuth2 Token Local Folder Mode

Establishes secure connectivity to both the legacy SSRS/PBIRS server and the target Bold Reports Enterprise instance. For offline or air-gapped setups, the Local Folder Import mode allows picking a local folder containing .rdl files and automatically extracting shared data sources and data sets without live network access.

  • Source Live Connection: Supports SSRS 2008 R2, 2012, 2014, 2016, 2017, 2019, and Power BI Report Server via SOAP Web Services and modern REST APIs.
  • Destination Live Connection: Connects to Bold Reports Enterprise Server (Docker container, on-premises Windows/Linux, or Bold Reports Cloud) via OAuth2 Bearer token authentication.
  • Health Probing: Live ping with roundtrip latency measurement before proceeding.

Technical Flow

POST /api/migration/runs { "sourceUrl": "http://ssrs-server/ReportServer", "sourceAuthType": "Ntlm", "destinationUrl": "http://boldreports:8090", "destinationTenantId": "site1" }
2
Inventory & Automated Compatibility Assessment
Catalog Discovery, Complexity Scoring & Classification
Catalog Crawl Rules Engine CSV / JSON Export

Crawls the entire catalog hierarchy (Folders, Data Sources, Data Sets, Reports). The static analyzer evaluates each RDL element against the Bold Reports engine specification and places reports into four actionable buckets:

  • Clean: 100% compatible standard controls (Tablix, Charts, Gauges, Textboxes, Subreports) requiring no manual intervention.
  • Auto-Fixed: Transformed automatically (namespace migration, connection string redaction, expression adjustments).
  • Needs Review: Custom assemblies (e.g. System.Web), complex VB.NET script blocks, or custom security extensions.
  • Blocked: Missing shared data source references, broken circular dependencies, or corrupt XML.

Report Estate Export

Export the complete assessed catalog with category tags, compatibility scores, and dependency trees to CSV or JSON for stakeholder review.

GET /api/migration/estate/export?format=csv
3
Dependency Resolution & RDL Transformation
Topological Sort DAG & Semantic XML Rewriting
Topological Sort DAG XML Namespace Rewrite Shared DS Rebinding Expression Tester

Prevents upload failures by executing a Directed Acyclic Graph (DAG) topological sort. Items are strictly sequenced so prerequisites exist before dependents are created.

  • Dependency Order: Folders ➔ Shared Data Sources ➔ Shared Data Sets ➔ Dependent Reports & Subreports.
  • Schema Rewriting: Migrates Microsoft RDL schemas (2005/01, 2008/01, 2010/01, 2016/01) to the Bold Reports specification.
  • Data Source Re-binding: Re-maps legacy connection strings and binds shared data sources to their new Bold Reports IDs.
  • Expression Sandbox: In-browser VB.NET expression tester to evaluate conditional formulas and string formatting expressions against sample data.

DAG Pipeline Sequence

Stage 1: Folder Hierarchy
Stage 2: Shared DataSources (RDS)
Stage 3: Shared DataSets (RSD)
Stage 4: Transformed RDL Reports
4
Automated Validation & Official Web Report Designer
Data Parity, Pixel Diff & Live In-Browser Report Designer
Data Parity Check XML Diff Viewer Embedded Designer Sign-off Workflow

Validates migrated reports using multi-tier comparative analysis and provides four specialized review tools:

  • Automated Data Parity: Compares row counts, column structures, and cell value fingerprints between SSRS and Bold Reports.
  • XML Diff Viewer: Side-by-side view showing original SSRS RDL vs transformed Bold Reports RDL with line-by-line additions and modifications highlighted.
  • Visual Comparison: Pixel-by-pixel rendering diff detecting layout shifts, margin inconsistencies, and font discrepancies.
  • Official Bold Reports Web Report Designer (Server-Integrated): Full visual report designer embedded directly in the application using official Syncfusion CDN scripts. Connects via live OAuth2 token to open, preview, edit, and save reports directly back to Bold Reports Server!

Designer Integration Config

serviceUrl: "/reporting/reportservice/api/Designer" reportServerUrl: "/reporting/api/site/{tenant}" serviceAuthorizationToken: "bearer <token>" reportPath: "/Finance/QuarterlyRevenue"
5
Batch Upload & Live Execution Engine
Streaming Progress, Live Logging & Bulk Destination Cleanup
Pause / Resume Retry Mechanism Live Console Log Bulk Delete Option

Executes the multi-stage upload into Bold Reports with idempotency guarantees, progress streaming, and administrative server cleanup tools:

  • Real-Time Execution Log: Live formatted logs with timestamp, event code (e.g. [UP-001]), and color-coded level badges ([INFO], [WARN], [ERROR]).
  • Pipeline Controls: Start, Pause, Resume, or Retry Failed items without starting from scratch.
  • Bulk Delete & Destination Reset: Clean up test runs directly from the UI:
    • Delete All: Direct live scan of all reports on Bold Reports Server with complete reset.
    • Delete by Section / Category: Select specific category folders to wipe and rebuild.
    • Delete Selected: Delete specific reports by item ID or name.

Live Log & API Controls

POST /api/migration/runs/{id}/upload GET /api/migration/runs/{id}/log POST /api/migration/runs/{id}/delete-destination { "deleteAll": true, "deleteCategories": true }
6
Production Cutover & Transparent URL Shim Proxy
Zero Downtime, Pre-Flight Gates & URL Redirection Shim
Reverse Proxy Shim Pre-Flight Gates Zero App Downtime Sign-Off Audit Package

Activates the cutover without requiring immediate changes to downstream applications, ERP systems, scheduled bookmarks, or emails:

  • Pre-Flight Gate Validation: Verifies that all reports are approved, shared data sources are online, and no orphan references exist before authorizing cutover.
  • Transparent URL Shim (Reverse Proxy): Intercepts requests sent to legacy SSRS URL formats:
    Legacy: http://ssrs-host/ReportServer?/Finance/MonthlySales&rs:Format=PDF
    Shim Proxy ➔ http://bold-host/reporting/site/site1/reports/view/Finance/MonthlySales
  • Sign-Off Package: Automatically exports a signed audit package containing diff summaries, validation scores, and execution timestamps for compliance.

Cutover Pre-Flight Status

[PASS] Shared DataSources Bound
[PASS] Validation Threshold Met (>95%)
[READY] Shim Proxy Route Activated
