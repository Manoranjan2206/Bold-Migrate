The 4-Step Guided Migration Workflow

Centered milestone walkthrough with contextual drawers, plus Settings & Power Utilities in the top header for bulk remap, cleanup, and advanced tuning.

1
Source & Target
Live SSRS Server, Streamlined Local .RDL Folder, Quick Scan & Slide-Over Data Source Vault
REST v2.0 / SOAP 2010 3 Entry Modes Progressive Auth Data Source Drawer

Choose between Live SSRS Server migration, streamlined Local .RDL Folder import, or zero-login Quick Scan Only. Establishes read-only SSRS connectivity and Bold Reports authentication, stages the catalog, and flags any SQL credentials needed in a contextual slide-over drawer.

  • Source Auto-Detection: Probes SSRS 2017–2022 / PBIRS via REST API v2.0 and falls back to SOAP ReportingService2010 for SSRS 2012–2016.
  • Contextual Data Source Drawer: Opens automatically if discovered shared data sources use Store credentials, with live validation and SQL TLS trust toggle.
  • Advanced Utilities in Settings: Bulk Host/Database/Credential Remapping (.rsds), Credential Vault mode, and Local Folder folder/auth overrides live under ⚙ Settings & Utilities.

Technical Flow

POST /api/migration/runs/{id}/connect POST /api/migration/runs/{id}/connect-destination POST /api/migration/runs/{id}/fetch POST /api/migration/runs/{id}/check POST /api/migration/runs/{id}/datasources/bulk-remap
2
Assess & Resolve
Unified Compatibility Readiness, Catalog Selection, Dependency Audit & Floating Multi-Select Bar
RDL 2008/2010 ➔ 2016 Compatibility Rules JSON Link & Cycle Audit

Combines compatibility scoring and report selection into a single workspace. Review readiness tiles against data/compatibility-rules.json, verify subreport/dataset/datasource links, rebind broken references in-place, and select reports for validation.

  • Semantic XML Rewriting: Strips UTF-8 BOMs, upgrades RDL 2008/01 and 2010/01 namespaces to 2016/01, and normalizes subreport/drillthrough paths via System.Xml.Linq.
  • Dependency & Cycle Verification: Audits DataSourceReference, SharedDataSetReference, and Subreport targets, detecting broken links, circular subreport chains, and offering one-click XML rebinding.
  • Selective Scoping & Floating Action Bar: Persist selected reports via select-reports or run destination server cleanup directly from the bottom floating action bar.

Assessment & Library APIs

GET /api/migration/runs/{id}/poll GET /api/migration/runs/{id}/reports POST /api/migration/runs/{id}/select-reports GET /api/migration/runs/{id}/dependencies/verify POST /api/migration/runs/{id}/reports/{reportId}/rebind-reference
3
Visual Verify
Headless Playwright (printMode Body-Only), Local Viewer/Designer & Swipe/Pixel Diff
Playwright printMode Local Staged Designer XML Diff Swipe & Pixel Diff

Validates staged reports locally before uploading anything to Bold Reports Server, using body-only printMode: true snapshots so parameter/toolbar chrome never skews SSRS comparisons:

  • Headless Playwright Validation: Renders staged reports concurrently via preview-runner.html, classifying Passed, DataSourceOffline (valid RDL, DB offline), NeedsManualCheck (prompt parameters), and Failed (with server render logs).
  • Local Staged Viewer & Web Report Designer (15.1.17): Preview and edit staged reports in-browser via StagedReportServer. Saving writes edits back to staging and marks LocalEditPendingUpload for Step 4.
  • RDL XML Diff & Visual Comparison: Inspect original vs. transformed RDL XML, or compare the local Playwright snapshot against live SSRS PNG output (or a Reference PNG) using Swipe Slider, Side-by-Side, and Canvas Pixel-Diff.

Local Preview & Validation APIs

POST /api/migration/runs/{id}/validate-render?concurrency=5 GET /api/migration/runs/{id}/validation-summary GET /api/migration/runs/{id}/reports/{reportId}/rdl POST /api/preview/runs/{id}/viewer/PostReportAction POST /api/preview/runs/{id}/designer/PostDesignerAction
4
Publish & Cutover
4-Stage Dependency Upload, Pre-Flight Gates, Delta Sync, URL Shim & Audit Package
Skip / Overwrite / Rename Dry-Run Plan 5 Blocking Gates URL Shim & Bundle

Executes the strict 4-stage dependency upload into Bold Reports Server (Folders ➔ Data Sources ➔ Shared Datasets ➔ Reports), validates pre-flight cutover gates, syncs late source changes, activates legacy SSRS URL redirection, and exports compliance artifacts:

  • Upload Pipeline & Conflict Policies: Preview with Dry-Run Plan, choose Skip/Overwrite/Rename, monitor live execution logs, push Step 3 local edits automatically via PUT /v1.0/reports, or inspect/launch uploaded reports directly on Bold Reports Server.
  • Pre-Flight Cutover Gates & Delta Sync: Verifies uploaded reports, measured validations, zero pending manual reviews, zero failed items, and zero unprocessed selected reports; runs incremental SHA-256 Delta Sync while preserving local edits.
  • Transparent URL Shim: Intercepts legacy SSRS URLs and redirects safely to Bold Reports:
    Legacy: /ReportServer?/Finance/MonthlySales&rs:Format=PDF
    Shim ➔ /reports/{id}/MonthlySales?exportFormat=PDF
  • Audit Artifacts: Download the Migration Run Report (report-pdf) and Support Bundle ZIP (run.json, reports.json, audit-events.json).
